# Framework Laptop Wallpapers

A personal collection of wallpapers inspired by Framework Laptop's modular design, repairability philosophy, and technical aesthetics.

## About

This repository contains custom-made wallpapers celebrating the Framework Laptop ecosystem. Each design draws inspiration from different aspects of Framework's innovative approach to laptops, from technical CAD blueprints to artistic interpretations of modularity and sustainability.

## Gallery

### Technical Series
- **CAD Blueprint** - Clean technical drawings showcasing Framework's engineering
- **CAD Exploded View** - Deconstructed view of Framework's modular architecture
- **Stealth Eclipse** - Minimal dark aesthetic
- **Aluminum Stealth** - Industrial material focus

### Artistic Series
- **Kintsugi Emerald** - Japanese art of repair meets Framework's repairability ethos
- **Modules** - Celebration of Framework's expansion card system
- **Rosone** - Geometric pattern inspired by modular design
- **LED Matrix** - Digital aesthetic
- **Labyrinth** - Technical maze design
- **Blueprint Plant** - Organic meets technical
- **Screws/Viti** - Highlighting Framework's repair-friendly fasteners

## Resolutions

Wallpapers are available in multiple resolutions:
- **2880×1920** (3:2 aspect ratio - Framework 13)
- **3840×2160** (16:9 4K)
- Custom resolutions for specific designs
